# FUFI Fulfillment Demo

Dual-sided fulfillment prototype for a Toronto-based operation.

## Views
- Customer: select vaulted items, enter an address, compare shipping options, request shipment, and track delivery.
- Fulfillment Ops: verify the request, pack items, enter final parcel dimensions, re-rate, create a label, dispatch, and advance tracking.

## Shipping model
The current demo uses illustrative simulated rates. It is designed so Chit Chats can be the primary Canada/US integration, with additional carriers added through adapters later.

## Run locally
Open `index.html` directly in a browser.
